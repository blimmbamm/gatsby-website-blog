I built this website for my brother’s business with the goal of delivering a fast, reliable static site. To achieve this, I chose `Next.js` with static site generation, ensuring optimal performance and SEO. The content is managed through `Sanity Studio`, which I quickly discovered is an incredibly powerful CMS. I enhanced its Rich Text editor with custom block types, such as an image gallery, to provide more flexibility and visual appeal.

Additionally, I set up the workflow so that a new deployment is automatically triggered from within Sanity Studio via a Vercel webhook, making content updates seamless and hassle-free.
